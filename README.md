# React Personal Profile (English Version)

An English-only React + Vite personal portfolio template.

## Features

- English UI
- One-line hero name
- Avatar integrated from your provided image
- Public transport / green mobility inspired color palette
- Responsive layout
- Easy-to-edit content in `src/data.js`
- Ready for a future language switch because all display text is centralized in `src/data.js`

## Run locally

```bash
npm install
npm run dev
```

## Main files

- `src/data.js` → profile content and UI labels
- `src/App.jsx` → page layout
- `src/styles.css` → styling
- `public/assets/avatar-profile.png` → avatar image
